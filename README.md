# 온(ON)마을 복(福) 터졌네! — 공동체 주사위 골든벨

관람: https://chuseok-eight.vercel.app/game  
담당자: https://chuseok-eight.vercel.app/admin

## 행사 진행
1. 담당자가 기존 계정으로 로그인하고 **조작권 이어받기**를 누릅니다.
2. **게임 시작** → 관장님팀 / 구청장팀 / 지회장팀 소개 → START → 게임판.
3. 실물 주사위를 던지고 **1~6 숫자 선택 → 주사위 공개**를 누릅니다. 웹에서 무작위 결과를 결정하지 않습니다.
4. 주사위 연출 → 한 칸씩 이동 → 도착 → 문제 자동 공개 → 제한시간(기본 20초).
5. 퀴즈 시간 종료 → 정답판 안내 3초 → 정답 자동 공개. 담당자가 **정답·성공 / 오답**을 판정합니다. 미션은 제한시간 종료 후 성공 여부를 판정합니다.
6. 판정 즉시 점수·성공 횟수를 저장하고 결과 연출 → 다음 팀 안내 2.6초 → 다음 팀 활성화. 순서는 **관장님팀 → 구청장팀 → 지회장팀**입니다.
7. 기본 29회 도전 후 최종 결과를 발표합니다. 총 진행 횟수는 행사 설정에서 변경 가능합니다. 실패·건너뛰기·쉬어가는 칸도 한 차례로 셉니다.

## 현장 수동 조작
**일시정지**는 말 이동, 주사위, 타이머, 오프닝, 결과·팀 전환, 피날레 자동 공개를 멈춥니다. **계속 진행**은 남은 시간부터 재개합니다. 정지 중에도 **이전 단계 / 다음 단계**로 수동 진행할 수 있습니다.

현재 문제/정답 다시보기, 타이머 재시작, 현재 팀 변경, 말 위치 수정, 점수 직접 수정, 성공 횟수 수정이 가능합니다. 이전 단계는 저장된 이전 진행 상태로 돌아가므로 해당 단계 이후의 점수 변경도 되돌립니다. 이미 판정한 문제를 다시 보여주어도 자동으로 점수나 성공 횟수를 중복 지급하지 않습니다. 다음 단계로 미판정 문제를 건너뛸 때는 확인창이 나옵니다.

말은 출발 → 01 → … → 29 → 출발로 순환합니다. 같은 칸의 말은 나란히 배치하며 서로 잡지 않습니다.

## 배점과 공동체 규칙
- 추석퀴즈 / 우리동네퀴즈: 파랑, 10점
- 노래퀴즈: 하늘색, 15점
- 팀미션: 초록, 15점
- 찬스: 골드, 20점
- 응원미션: 보라, 20점
- 기존 기타 문제 유형도 유지합니다. 추억·건강·스마트퀴즈 10점, 몸짓 15점, 기존 보너스 50점.

위 통일 배점은 과거 시트의 배점 값보다 우선합니다. 기존 획득 점수는 소급 변경하지 않습니다. 수동 가감점은 성공 횟수에 영향을 주지 않습니다.

성공 판정마다 해당 팀 성공 횟수 +1. 같은 도전의 판정 중복은 방지하며, 새 차례에서 다시 도전한 문제는 새로운 성공으로 셉니다. **8회 이상 성공해야 최종 점수가 인정됩니다.** 7회 이하는 획득 점수가 있어도 최종 점수 0점입니다. 팀 카드에는 획득 점수와 성공 n/8을 표시합니다. 피날레는 획득 점수·성공 여부를 먼저 보여주고 인정 점수로 순위를 순서대로 공개합니다. 동점은 공동 순위입니다.

## 기존 데이터 유지
기존 Supabase 테이블, Auth/RLS, 관리자 계정, 팀별 점수·위치, 29개 문제와 Google Sheets 주소를 유지합니다. 새 형식 최초 접속은 START 화면이며 기존에 없던 성공 횟수는 0부터 시작합니다. 이미 진행한 성공 기록이 있다면 담당자가 성공 횟수를 직접 입력해 주세요. 기존 진행 중 문제/타이머는 새로운 규칙의 START에서 다시 시작합니다. 게임 초기화는 확인 후 실행하며 문제은행을 삭제하지 않습니다.

Supabase JSON 상태에 communityVersion, successes, paused, pausedAt, flow, move, dieInput, openingIndex, finaleIndex를 저장합니다. 화면 전환은 저장된 단계·기한으로 처리하므로 다른 담당자 PC에서도 이어받을 수 있습니다. 행사 중 담당자 창 하나를 열어두세요. 인터넷 끊김 중에는 마지막 화면을 유지하며 복구 후 조작권을 이어받습니다.

## 문제 수정
기존 Google Sheets 공유 주소나 Apps Script /exec 주소를 담당자 화면의 **Google Sheets 문제은행**에 입력하고 **문제 새로고침**을 누릅니다.

칸번호 / 유형 / 제목 / 문제 / 보기1 / 보기2 / 보기3 / 보기4 / 정답 / 미션내용 / 제한시간 / 사용여부

기존 선택 열 '배점'이 있어도 오류 없이 읽으며 통일 배점을 적용합니다. 칸번호 1~29, 제한시간 5~600초, 사용여부 TRUE/FALSE. 객관식은 보기 2~4개와 정답, 미션은 보기·정답을 비우고 미션내용을 입력합니다. 불러오기 실패 시 마지막 문제를 유지합니다. 새 성공 횟수나 점수는 시트 새로고침으로 초기화되지 않습니다.

## 다른 컴퓨터 / 개발 / 배포
행사 운영은 공개 링크만 열면 됩니다. 관람 화면은 로그인 없이 읽기만 가능하며 담당자만 수정합니다.

소스 수정: Node.js 22 이상 설치 후
```
git clone https://github.com/qlcdywjd20-max/chuseok.git
cd chuseok
npm install
```
.env.example을 .env.local로 복사하고 Supabase URL과 publishable key를 입력합니다. 비밀번호·secret/service_role 키를 넣지 마세요. .env.local은 Git에서 제외됩니다.
```
npm run dev
npm run build
npm test
```
Vercel: 저장소 Import → Framework Other → Build `npm run build` → Output `dist` → VITE_SUPABASE_URL / VITE_SUPABASE_PUBLISHABLE_KEY 환경변수 → Deploy. 기존 연결 프로젝트는 main 변경 시 자동 배포하며 환경변수를 다시 설정할 필요가 없습니다.

app.js: 게임 단계·배점·UI / cloud.js: 기존 인증·저장·실시간 / index.html: 방송 디자인 / supabase.sql: 기존 권한 구조. 테스트는 진행·일시정지·공동체 규칙, Sheets 파서, PostgreSQL RLS·정답 보호를 확인합니다.

LIVE/50개소 표시는 행사 브랜딩이며 실제 화상회의 접속 수 측정값은 아닙니다. 효과음은 담당자 창에서만 재생합니다.
