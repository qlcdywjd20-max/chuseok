# 온(ON)마을 복(福) 터졌네! — 한가위 주사위 골든벨

동백꽃노인종합복지관과 스마트경로당 50개소를 위한 16:9 방송 보드게임입니다. 기존 Supabase 데이터와 관리자 계정을 그대로 사용합니다.

- 관람 화면: https://chuseok-eight.vercel.app/game (로그인 불필요)
- 담당자 화면: https://chuseok-eight.vercel.app/admin
- 소스 저장소: https://github.com/qlcdywjd20-max/chuseok

## 행사 진행

1. 담당자 화면에 등록한 이메일과 비밀번호로 로그인하고 **조작권 이어받기**를 누릅니다.
2. **게임 시작**을 누르면 START 화면에서 보드로 이동합니다.
3. 팀을 확인하고 **주사위 던지기**를 누릅니다. 실제 주사위를 사용하면 접힌 메뉴에서 1~6칸을 직접 입력할 수 있습니다.
4. 주사위 연출 후 말이 한 칸씩 이동합니다. 출발 → 01 → 02 → … → 29 → 출발 순서로 계속 순환합니다. 말이 같은 칸에 있어도 함께 머뭅니다.
5. 도착한 문제를 1.5초 뒤 공개합니다. 객관식은 기본 20초 타이머가 시작됩니다. 문제별 제한시간을 지정하면 그 시간을 사용합니다.
6. 시간이 끝나도 정답은 자동 공개되지 않습니다. 담당자가 **정답 공개 → 정답·성공 / 오답 → 다음 진행 → 다음 팀** 순서로 진행합니다. 필요하면 타이머 중에도 정답을 공개할 수 있습니다.
7. 기본 29회 진행을 마치면 최종 순위를 표시합니다. **말 위치·행사 설정 → 총 진행 횟수**에서 변경할 수 있고 **최종 결과**로 조기 발표도 가능합니다. 이동하지 않는 수동 문제도 1회로 셉니다. 여러 번 방문한 같은 칸도 새 도전 1회입니다.

중앙 점수판은 관장님팀(골드), 구청장팀(파랑), 지회장팀(초록) 순서입니다. 기본 진행 순서는 구청장팀 → 관장님팀 → 지회장팀입니다. 기존 DB의 팀 배열 순서를 유지하므로 팀별 점수가 다른 팀으로 바뀌지 않습니다.

## 점수와 문제은행

기본 배점은 일반·노래 퀴즈 10점, 몸짓·미션 20점, 찬스 30점, 보너스 50점입니다. 정답/성공 버튼으로 한 문제당 한 번만 반영합니다. 찬스 카드를 뒤집는 것만으로 점수를 주지 않으며 담당자가 성공을 눌러야 합니다. 수동 +10/+20/+30/−10은 별도로 사용할 수 있습니다.

**문제 선택·배점 수정**에서 각 칸 배점을 바꾸고 서버에 저장할 수 있습니다. Google Sheets를 불러오면 시트의 배점으로 갱신됩니다.

시트 열:

`칸번호 / 유형 / 제목 / 문제 / 보기1 / 보기2 / 보기3 / 보기4 / 정답 / 미션내용 / 제한시간 / 사용여부 / 배점`

마지막 **배점**은 선택 열입니다. 비우면 유형별 기본 점수를 사용합니다. 0~999의 정수를 입력합니다. 기존 12열 시트도 계속 작동합니다. 객관식은 보기 2~4개와 정답(번호 또는 보기 내용), 미션은 보기·정답을 비우고 미션내용을 입력합니다. 칸번호는 중복 없이 1~29, 제한시간은 5~600초, 사용여부는 TRUE/FALSE입니다.

지원 유형: 추석퀴즈, 우리동네퀴즈, 추억퀴즈, 스마트경로당퀴즈, 건강상식, 노래퀴즈, 몸으로 말해요, 팀미션, 찬스, 특별찬스, 보너스, 응원전. 이전 골든미션 유형은 보너스로 표시됩니다.

담당자 화면에서 **Google Sheets 문제은행**을 열고 시트 공유 주소 또는 Apps Script `/exec` 주소를 넣은 뒤 **문제 새로고침**을 누릅니다. 구글시트 직접 연결에는 링크 열람 권한이 필요합니다. 주소·마지막으로 불러온 문제는 Supabase에 저장합니다. 연결 실패 시 기존 문제를 유지합니다. 시트 변경은 자동 반영되지 않습니다.

Apps Script 사용자는 `문제은행-AppsScript.gs`를 사용합니다. 기존 스크립트에 배점 열 전달을 추가했다면 웹앱 배포도 새 버전으로 업데이트해야 합니다. 직접 시트 연결은 이 작업이 필요 없습니다.

## 기존 행사 데이터 전환

기존 팀 점수, 29개 문제 ID, 문제 내용, 시트 주소, 관리자 계정과 접근 권한을 유지합니다. 새 화면을 처음 열 때 START로 표시하고 첫 조작권 획득 시 주사위 상태를 저장합니다. 기존 숫자 위치는 같은 번호로 보존하며 완주 상태는 출발로 전환합니다. 기존에 진행 중이던 문제/타이머는 종료하고 새 START에서 시작합니다. 새 게임으로 시작하려면 담당자가 **게임 초기화**를 누르세요.

DB 테이블을 새로 만들거나 기존 데이터를 삭제할 필요가 없습니다. 사용 테이블은 `game_state`, `game_private`, `game_admins` 그대로입니다. JSON 상태에 `diceVersion`, `dice`, `completed`, `totalTurns`, `scoreFx`, `roundOpen`을 추가했습니다. 서버의 버전 검사, 15초 조작권, RLS, 공개 전 정답 보호를 유지합니다.

## 다른 컴퓨터에서 사용 / 수정

행사 운영은 위 공개 링크만 열면 됩니다. 관람 PC는 `/game`, 담당자 PC는 `/admin`을 엽니다. 같은 서버 상태를 보며 담당자 창 한 개는 행사 내내 열어둡니다. 인터넷이 끊기면 마지막 화면을 유지하고 복구 후 조작권을 다시 이어받습니다.

소스 수정은 Node.js 22 이상 설치 후:

```sh
git clone https://github.com/qlcdywjd20-max/chuseok.git
cd chuseok
npm install
```

`.env.example`을 `.env.local`로 복사한 뒤 Supabase Project URL과 publishable key를 입력합니다. 비밀번호나 secret/service_role 키를 넣지 마세요. `.env.local`은 Git에서 제외됩니다.

```sh
npm run dev
npm run build
npm test
```

로컬 주소는 `http://127.0.0.1:5173/admin`, `http://127.0.0.1:5173/game`입니다. 이는 해당 PC에서만 열립니다. 다른 PC와 공유할 때는 위 Vercel 주소를 사용하세요.

Vercel: GitHub 저장소 Import → Framework Other → Build `npm run build` → Output `dist` → `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY` 환경변수 설정 → Deploy. 연결된 프로젝트는 main 변경 시 자동 배포합니다. 기존 프로젝트의 환경변수는 다시 만들 필요가 없습니다.

## 구조와 검증

- `index.html`: 폰트를 포함한 방송/담당자 화면 템플릿. 빌드 후 실행합니다.
- `app.js`: 외곽 경로, 주사위, 문제, 배점, 순위, 연출, 시트 파서.
- `cloud.js`: Supabase 로그인, 권한 확인, 실시간 구독, 저장, 연결 복구.
- `board-data.json`: 신규 설치용 기본 문제 데이터. 운영 중 문제는 DB와 시트가 원본입니다.
- `supabase.sql`: 신규 서버용 테이블/RLS/RPC. 기존 서버는 그대로 사용합니다.
- `test.cjs`, `security-test.cjs`: 이동·데이터 전환·타이머·배점·종료 및 PostgreSQL 권한 테스트.

LIVE/50개소 표시는 행사 브랜딩이며 실제 화상회의 접속 수를 측정하지 않습니다. 효과음은 담당자 창에서만 재생합니다. 관리자 비밀번호는 Supabase Authentication에서 관리합니다.
